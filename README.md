🧠 **ML / NLP**

Проекты в области нейросетей и обработки данных:

- **Мультимодальная регрессия (калорийность блюд)** — BERT + EfficientNet, PyTorch.  
  Объединение текстовых и визуальных признаков для предсказания числового значения.  
  Реализован полный пайплайн: загрузка данных, аугментация, обучение, инференс.

- **NER (извлечение сущностей)** — BERT, PyTorch, BIO-разметка.  
  Модель для распознавания именованных сущностей в текстах (PERSON, ORG, LOC и др.).  
  Настройка пайплайна токенизации, выравнивание меток, обучение с двумя головами (NER + CLS).

- **Генерация текста** — LSTM, GRU, PyTorch.  
  Обучение языковых моделей на пользовательских текстовых данных, сравнение архитектур.

- **Инференс и оптимизация** — квантизация, батчинг, ONNX, работа с GPU и CPU.
